# 🚀 Developer Portfolio & Interactive Web Apps

Welcome to the official repository for my personal developer portfolio! This project showcases a collection of full-stack and front-end web applications built using modern web standards, Python (Flask), and SQLite.

---

## 🌟 Featured Projects

Here are the live web applications currently featured in this portfolio:

### 1. [Orbis CRM Web App](https://tb2msslintcrm1.netlify.app/)
* **Description:** A full-stack customer relationship management (CRM) tool built using Python, Flask, and SQLite.
* **Key Features:** Secure user authentication, dynamic data entry tables, and clean, responsive dashboard layouts.

### 2. [Basic CRM](https://lead-crm-wug0.onrender.com/)
* **Description:** A front-end single-page dashboard designed for tracking session statistics, progress notes, and media records.
* **Hosting:** Cleanly hosted via GitHub Pages / Render.

### 3. [Space Weather Research](https://tushar-tb2.github.io/swr/)
* **Description:** An interactive research web platform dedicated to visualizing space weather phenomena, solar data metrics, and atmospheric telemetry.

### 4. [Monthly Newsletter Generator](https://tb2msslmonthlyreportgenerator.netlify.app/)
* **Description:** A productivity utility web app designed to streamline monthly report structuring, content layout generation, and document exporting.

## 🛠️ Tech Stack & Skills

* **Languages:** Python, JavaScript, HTML5, CSS3

## ✨ Features

* **Responsive Design:** Fully responsive layout styled with modern CSS variables, clean typography, and a dark-mode theme.
* **Admin Mode Toggle:** Includes a built-in interactive admin control bar allowing inline text editing directly in the browser session.
* **AI Content Assistant:** Built-in simulated AI integration (`triggerAI`) to instantly rewrite and enhance project descriptions and professional summaries on the fly.
